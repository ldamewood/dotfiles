# MacBook Pro Configuration

This directory contains the nix-darwin configuration for the MacBook Pro —
the primary interactive workstation (full GUI apps, Homebrew casks).

For Linux Builder VM management (start/stop/reboot/cache/SSH), see
[`../LINUX_BUILDER.md`](../LINUX_BUILDER.md) — mbp and `squash` share the
same `linux-builder.nix` module.
